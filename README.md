# مسارك للإنجاز السياحي (MASARIK TOURISM)

تطبيق أندرويد متكامل مبني باستخدام **Kotlin** و **Jetpack Compose** وفقاً لمعايير **Material Design 3**.

## عن التطبيق
وكالة مسارك للإنجاز السياحي هي وكالة معتمدة وموثقة متخصصة في خدمات تأشيرات المملكة العربية السعودية وبرامج الحج والعمرة، توثيق المعاملات، حجز تذاكر الطيران، وحجز الفنادق.

## الميزات والخدمات المتاحة
- **تأشيرات السعودية ومنصة إنجاز:**
  - حجز مواعيد البصمة تساهيل VFS Tasheer المباشرة
  - تسديد طلب منصة إنجاز وتسديد رسوم التأمين الطبي
  - إنشاء وطباعة الباركود الخاص بالموعد
  - تأشيرات الزيارة العائلية والشخصية والعمل والاستقدام والسياحة
- **الكشف الطبي المعتمد GAMCA / LAB:**
  - حجز فوري في معامل جامكا المعتمدة وإصدار الباركود
  - متابعة النتائج وتوثيق شهادات التطعيمات
- **برامج العمرة B2C والحج:**
  - إصدار تأشيرة B2C مع الباركود النظامي
  - برامج عمرة ميسرة وفنادق قريبة من الحرم المكي والنبوي
- **حجز الطيران والفنادق:**
  - تذاكر طيران دولية وداخلية بأفضل الأسعار
  - فنادق 5 نجوم وشقق فندقية عائلية
- **توثيق المستندات:**
  - توثيق الغرفة التجارية المصرية ووزارة الخارجية
- **طرق الدفع الآمنة:**
  - الدفع الإلكتروني عبر بوابة Paymob (بطاقات فيزا/ماستركارد ومحافظ إلكترونية)
  - التحويل البنكي وإنستاباي عبر الواتساب
  - الدفع نقداً في فروع القاهرة والدقهلية
